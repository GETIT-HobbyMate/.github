# 🗺️ HobbyMate (하비메이트)

> **"나만의 취미를 함께할 가장 가까운 메이트를 찾는 곳"** > 경북대학교 IT대학 컴퓨터학부 대학생 초압축 개발 스프린트 프로젝트 (2026.05.22 ~ 2026.05.30)

---

## 🎯 Project Overview
**HobbyMate**는 같은 취미를 공유하고 싶지만 주변에서 같이 할 사람을 찾기 어려웠던 대학생들을 위한 **근거리 기반 취미 메이트 매칭 서비스**입니다. 긴 기획 기간을 거쳐, 8일간의 초압축 스프린트를 통해 안정적이고 유기적인 웹 서비스를 빌드합니다.

* **스프린트 기간:** 2026년 5월 22일 ~ 2026년 5월 30일 (8 Days Sprint)
* **목표:** MVP(최소 기능 제품) 구현 및 프론트-백엔드 완전 연동

---
